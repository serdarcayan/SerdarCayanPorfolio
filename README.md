## Getting Started

### Prerequisites

- Node.js 18 or later
- npm 9 or later
- Git

### Installation

```bash
git clone https://github.com/serdarcayan/PersonalPortfolio.git
cd PersonalPortfolio
npm install
npm run dev
```

Vite will start the development server and display the local address in the terminal.

### Production Build

```bash
npm run build
```

The production-ready files are generated in the `dist/` directory.

To preview the production build locally:

```bash
npm run preview
```

## Deployment

The portfolio can be deployed to GitHub Pages using GitHub Actions.

The deployment workflow installs dependencies, builds the React application, and publishes the generated `dist/` directory.

For repository-based GitHub Pages hosting, configure the Vite `base` option to match the repository name:

```typescript
export default defineConfig({
  plugins: [react()],
  base: '/REPOSITORY_NAME/',
})
```

Replace `REPOSITORY_NAME` with the exact repository name. For a user site hosted at `USERNAME.github.io`, the base path is generally `/`.
