Portfolio Color Theme
=====================

Theme: Cool technical blue with cyan and restrained amber accents.

Core colors
-----------
Color           Hex         Tailwind class                 Usage
Deep navy       #12243A   text-[#12243a] / bg-[#12243a]  Primary text and strong contrast
Cyan            #0E7490   text-cyan-700 / bg-cyan-700    Main accent, labels, links, navigation
Cyan dark       #155E75   text-cyan-800 / bg-cyan-800    Strong accent text and controls
Blue            #2563EB   text-blue-600 / bg-blue-600    Secondary technology accent
Amber           #D97706   text-amber-600 / bg-amber-600  Warm highlight and hover accent
Slate           #475569   text-slate-600 / bg-slate-600  Supporting text
Page background #EDF4F8   bg-[#edf4f8]                   Main page background

Tailwind utility patterns
-------------------------
Primary heading:  text-[#12243a]
Accent label:     text-cyan-800
Accent button:    bg-cyan-800 text-white hover:bg-cyan-700
Warm hover:       hover:text-amber-600
Soft card:        border border-cyan-950/10 bg-white/80
Panel glass:      border border-white/80 bg-white/80 backdrop-blur-xl
Muted copy:       text-slate-600

Usage guidance
--------------
- Use deep navy for primary headings and readable body copy.
- Use cyan for interactive elements, section labels and active navigation.
- Reserve amber for small highlights and hover states.
- Keep large surfaces light and translucent; use the gradient glows sparingly.
- Use slate for secondary copy and supporting labels.
