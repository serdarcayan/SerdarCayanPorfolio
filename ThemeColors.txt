Portfolio Color Theme
=====================

Theme: Apple-inspired light interface with restrained system-blue accents.

Typography and accents
----------------------
Usage               Color / Tailwind class
Primary text        #1D1D1F / text-[#1d1d1f]
Secondary text      #424245 / text-[#424245]
Description         #515154 / text-[#515154]
Muted text          #6E6E73 / text-[#6e6e73]
Apple blue          #0071E3 / text-[#0071e3]
Blue hover          #0066CC / text-[#0066cc]
Warm accent         text-amber-700
Positive status     text-emerald-700

Surfaces and controls
---------------------
Page background     #F5F5F7
Glass panel         bg-white/70 backdrop-blur-xl
Glass card          bg-white/70
Card hover          hover:bg-white/90
Border              #D2D2D7 / border-[#d2d2d7]
Subtle shadow       shadow-sm shadow-black/5
Primary button      bg-[#0071e3] text-white
Primary hover       hover:bg-[#0066cc]
Secondary button    bg-white/80 text-[#1d1d1f]
Scrollbar           Apple-blue tint
Typography          -apple-system, BlinkMacSystemFont, Segoe UI

Usage guidance
--------------
- Keep surfaces bright, neutral and uncluttered.
- Use Apple blue for links, actions, selected states and icons.
- Use near-black for primary text and soft gray for supporting copy.
- Reserve warm and green colors for small semantic accents.
- Prefer subtle borders, shadows and background gradients.
